# 隠された情報のもとでの妨害のタイミング

[繁體中文](README.md) · [English](README.en.md) · **日本語**

D.D.クロウを今使うべきか、それとも温存すべきか。本研究は『遊戯王』の墓地除外をめぐる判断を出発点に、相手の手札が分からない状況で、限られた妨害手段を目の前の脅威と後から現れる脅威にどう配分するかを考えます。

論文では、1回の行動で1つの対象を除去する二段階モデルを構築し、確実に防御を成功させるために必要な最小資源量を導きます。主な結果は次のとおりです。

- 資源量 $k$ ではすべての候補状態に対応できない場合、最大 $k+1$ 個の状態だけで、同時には対応できないことを示せます。
- 緊急対象をすべて除去した後も、各状態で最悪の場合に必要な後続資源量が少なくとも $d$ なら、上界は $1+\max(k-d,0)$ になります。どちらの上界も達成されます。
- どの2状態にも同時に対応できても、3状態全体には対応できない場合があります。相手の手札候補を読む際には、複数の可能性の間に生じる衝突も重要になります。
