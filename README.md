# 隱藏資訊下的干擾時機

**繁體中文** · [English](README.en.md) · [日本語](README.ja.md)

這階段交出 D.D. 烏鴉（D.D.クロウ），還是保留等待？本研究從《遊戲王》的墓地除外決策出發，探討玩家如何在對手持有隱藏資訊時，將有限的干擾資源分配給眼前與稍後出現的威脅。

論文建立兩階段、每次移除一個目標的數學模型，推導保證成功防守所需的最小資源量，並證明：

- 若資源量為 $k$ 時無法應付所有可能狀態，至多 $k+1$ 個狀態就足以構成無法同時應付的衝突。
- 在先移除所有緊急目標後，若每個狀態的最壞後續需求至少為 $d$，上界可收緊為 $1+\max(k-d,0)$；兩個界限都能達到。
- 任兩個狀態可以同時應付，三個合在一起卻可能失敗。因此，理解對手的可能手牌，也需要辨識多個可能性之間的整體衝突。
